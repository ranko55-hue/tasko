# אפיון מפורט (שלב 0) — טיוטה

> ⏳ ימולא בשלב האפיון המשותף. השאלות כאן הן הבסיס לפגישת האפיון.

## שאלות פתוחות לאפיון

### משתמשים ותפקידים
- [ ] כמה מנהלים / עובדים צפויים בארגון טיפוסי?
- [ ] האם מנהל יכול להיות גם עובד מבצע (תפקיד כפול)?
- [ ] האם נדרשת גישת צפייה ללקוח הקצה (שלב 2?)

### משימה — שדות
- [ ] אילו שדות חובה: כותרת, לקוח, עובד, תאריך יעד, עדיפות?
- [ ] אילו נתונים העובד מעדכן: סטטוס, הערות, שעות, חומרים, תמונות?
- [ ] רשימת סטטוסים: חדשה → נקלטה → בטיפול → הושלמה? מה עוד? (מבוטלת? ממתינה ללקוח?)

### תהליך עבודה
- [ ] מה קורה כשמשימה מוקצית — התראה לעובד? איך (מייל / בתוך המערכת / וואטסאפ בשלב 2)?
- [ ] האם עובד יכול להעביר משימה לעובד אחר, או רק מנהל?
- [ ] האם יש תת-משימות / צ'קליסט בתוך משימה?

### לקוחות קצה
- [ ] אילו פרטים נשמרים על לקוח: שם, ח.פ, אנשי קשר, כתובות אתרים?
- [ ] האם ללקוח יכולים להיות כמה אתרים/סניפים שמשימות משויכות אליהם?

### מסכים (רשימה ראשונית)
1. התחברות
2. לוח בקרה — מנהל (כל המשימות: לפי לקוח / עובד / סטטוס)
3. המשימות שלי — עובד
4. פרטי משימה + יומן אירועים
5. ניהול לקוחות
6. ניהול משתמשי הארגון
7. הגדרות ארגון
