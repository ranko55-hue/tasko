# מסמך התכנון הראשוני

המסמך המלא (Word) הוצג לשותף ואושר. עיקריו:

- MVP בתוך 8–10 שבועות: ארגונים, תפקידים (מנהל/עובד), לקוחות קצה, משימות, יומן אירועים, לוח בקרה
- אינטגרציות (חשבוניות, הזמנות) — שלב 2, דרך Make
- תקציב 3 חודשים: כלים ותשתית ~1,650 ₪ + תשתית קוד קיימת 4,000 ₪
- מודל עלויות: חלוקה שווה בין השותפים
